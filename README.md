## 🔍 Overview

This repository documents my path through the **DNC School Data Scientist program**, **completed on 16 March 2026 with a 292-hour workload** (certificate validation code `CERT-1773744056744-ORW3`). The course focuses on applying machine learning, statistics and predictive modeling to business problems with large volumes of data.

It covers the full data workflow: **Excel and Power BI** for business intelligence, **Python** for analysis, **statistics**, **data cleaning**, **regression and classification**, **clustering**, and **big data and AI apps** with PySpark, Streamlit and Hugging Face Transformers.

> 📝 Lesson notebooks are in Portuguese, the language of the course. The challenge projects listed below have standalone repositories in English.

## 🚀 How to Use

1. **Browse online:** open any module folder and click a notebook (`.ipynb`). GitHub renders it with its outputs.
2. **Run locally:**

   ```bash
   git clone https://github.com/Laurentius96/DNC-DataScience.git
   cd DNC-DataScience
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   jupyter notebook
   ```

   Some modules use extra packages (for example `pyspark`, `pycaret`, `streamlit`, `gradio` or `transformers`); install them as the notebook's first cell or `Materia_12-Modelos_Nuvem-e-IA/projetos/requirements.txt` indicates.
3. **Run in the cloud:** upload a notebook to [Google Colab](https://colab.research.google.com/) (File › Upload notebook).
4. **Power BI files** (`.pbix`) open in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) on Windows.
